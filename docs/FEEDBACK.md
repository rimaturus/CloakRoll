# Feedback history

What beta testers and users asked for, when, and what became of it. Newest first.
Status: **done** (in the version shown), **planned**, **declined** (with the reason).

## 2026-09-29 · internal test on Google Play (5 testers, build 1.6/1.7)

| # | Feedback | Status |
|---|---|---|
| 1 | Offer **OneDrive** as storage, not only Amazon Photos. | done in 1.8 (needs the Microsoft client ID in the build) |
| 2 | Offer **Google Drive** as storage. | done in 1.8 (needs the Google client ID in the build) |
| 3 | Option to keep the vault **only on the phone**, without any cloud. | done in 1.8: "Only on this phone", in a folder you choose |
| 4 | Keep an **encrypted copy on the phone as well**, together with the cloud. Asked at setup. | done in 1.8: setup toggle, also in Settings |
| 5 | **Estimated time** for uploads and downloads. | done in 1.8: time left in the progress line and notification |
| 6 | **Statistics** of upload, download, encryption and decryption times. | done in 1.8: Settings > Transfer statistics |
